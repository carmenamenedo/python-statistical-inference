# 📊 Statistical Analysis & Inference with Python

Statistical analysis and inference project developed using **Python**, covering descriptive statistics, probability distributions, data visualization and statistical estimation.

Developed as part of my **MSc in Big Data & Artificial Intelligence**.

## 📌 Project Overview

This project explores fundamental concepts in statistics through practical exercises, numerical calculations, simulations and visualizations.

The main objective is to apply statistical methods to real and simulated datasets, combining mathematical reasoning with Python programming.

## 🛠️ Technologies & Libraries

- Python
- NumPy
- SciPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 🔍 Main Topics

### 1. Descriptive Statistics

Exploratory analysis of datasets using statistical measures such as:

- Mean and median
- Variance and standard deviation
- Minimum and maximum values
- Data distributions and variability
- Graphical representations

### 2. Probability Distributions

Study and visualization of probability distributions, including:

- Uniform distribution
- Normal distribution
- Binomial distribution
- Poisson distribution

The exercises explore their statistical properties and behavior under different parameters.

### 3. Iris Dataset Analysis

Exploratory analysis of the well-known **Iris dataset**, containing measurements of flower characteristics.

The analysis focuses on understanding numerical variables, comparing observations and visualizing data distributions.

### 4. Data Visualization

Statistical visualizations are used to better understand patterns, variability and relationships between variables.

Techniques include:

- Histograms
- Boxplots
- Distribution plots
- Statistical comparisons

### 5. Sampling Distributions

Study of sampling variability through statistical simulations.

The exercises explore how sample size affects the behavior of statistical estimates and their precision.

### 6. Statistical Estimation

Introduction to statistical inference and parameter estimation, including likelihood functions and maximum likelihood estimation.
